# Portfolio de Zeineb Khaled

Portfolio personnel développé avec Next.js et React.

## Lancer le projet en local

1. Installer Node.js (version 20 ou supérieure).
2. Ouvrir un terminal dans le dossier du projet.
3. Installer les dépendances :

```bash
npm install
```

4. Lancer le serveur de développement :

```bash
npm run dev
```

5. Ouvrir http://localhost:3000 dans le navigateur.

## Personnalisation avant publication

- Remplacer le lien LinkedIn provisoire dans `app/page.tsx`.
- Vérifier les descriptions, les rôles personnels et les technologies de chaque projet.
- Ajouter des captures d'écran réelles des projets si disponibles.
- Vérifier les intitulés et dates des expériences.
- Ajouter éventuellement un CV PDF dans `public/` et un lien de téléchargement.
